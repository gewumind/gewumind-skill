## db 模块（默认引入）


无需 import，直接用。

| 方法 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `db.select(sql)` | String | List\<Map\> | 查询列表 |
| `db.selectInt(sql)` | String | int | 查询单值（int） |
| `db.selectOne(sql)` | String | Map | 查询单行 |
| `db.selectValue(sql)` | String | Object | 查询单值（任意类型） |
| `db.page(sql, limit?, offset?)` | String, long?, long? | Object | 分页查询 |
| `db.update(sql)` | String | int | 增删改 |
| `db.insert(sql, id?)` | String, String? | Object | 插入 |
| `db.cache(name, ttl?)` | String, long? | db | 启用缓存（链式） |
| `db.transaction(cb?)` | Function? | Object | 事务 |
| `db.camel()` | - | db | 列名转驼峰 |
| `db.upper()` / `db.lower()` | - | db | 列名转大/小写 |
| `db.pascal()` | - | db | 列名转帕斯卡 |
| `db.default()` | - | db | 列名保持原样 |
| `db.commit()` / `db.rollback()` | - | - | 手动事务（与 `db.transaction()` 配对） |

```js
// 基础查询
return db.select('select * from sys_user');
return db.selectInt('select count(*) from sys_user');
return db.selectOne('select * from sys_user limit 1');
return db.selectValue('select username from sys_user limit 1');
return db.page('select * from sys_user');  // 分页

// 缓存
return db.cache('user_list', 60000).select('select * from sys_user');

// 列名转换
return db.camel().select('select * from sys_user');
```

### 单表链式 API（1.0.0+）
```js
// insert
return db.table('sys_user').insert({ user_name: '李富贵', role: 'admin' });
// 等价: insert into sys_user(user_name, role) values('李富贵','admin')

// update
return db.table('sys_user').primary('id', '1').update({ user_name: '王二狗' });
// 等价: update sys_user set user_name = '王二狗' where id = '1'

// select
return db.table('sys_user').select();
return db.table('sys_user').page();

// where 条件（API 抄的 mybatis-plus）
return db.table('sys_user')
    .where()
    .like('user_name', '%李富贵%')
    .eq('role', 'admin')
    .select();

where 操作符：eq(==), ne(<>), lt, gt, lte, gte, in, notIn, like, notLike

// primary 必须在 update/save 前设置
// column(name) 设置要查询的列（select 有效）
// column(name, value) 设置要写入的列（非 select 有效）
```
